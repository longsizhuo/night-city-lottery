# Night City Lottery 0.2.0 · 夜之城随机队友（实验预发布）

随机摇一个临时队友，或带四人增援、安排最多 8 对 8 的街头混战。

## 下载与安装

下载 **NightCityLottery-0.2.0.zip**，退出游戏，把里面的 `bin` 目录合并到 Cyberpunk 2077 游戏根目录。

安装依赖后载入存档，到 CET → Bindings 手动设置快捷键：推荐 **F6 抽取、F7 召回、F8 清场**。这些按键不会自动覆盖已有绑定。

- [完整安装教程](https://github.com/longsizhuo/night-city-lottery/blob/main/docs/INSTALL.zh-CN.md)
- [玩法、8 对 8 控制台用法和常见问题](https://github.com/longsizhuo/night-city-lottery/blob/main/docs/GUIDE.zh-CN.md)
- [测试范围与已知问题](https://github.com/longsizhuo/night-city-lottery/blob/main/docs/TESTING.md)

实测组合：Windows PC / 游戏 2.5 / CET 1.38.1 / RED4ext 1.31.0 / Codeware 1.21.2 / redscript 0.5.32。依赖均由原作者单独提供，本安装包不包含依赖 DLL。

## 使用前了解

队友临时生成，剧情前请解散，读档后重新抽取。拍摄续航默认关闭；开启后演示 NPC 会不死。

**这是实验预发布。** 一次约 6 小时的本地会话出现过引擎整数溢出崩溃，原因未确认。当前不承诺长时间稳定，也不宣称该问题已修复。

GitHub 自动附带的 Source code 压缩包是源码；普通安装请使用命名的 MOD ZIP。`SHA256SUMS.txt` 可用于核对下载文件。
