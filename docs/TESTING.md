# 验证范围与已知问题

## 版本来源

v0.2.0 的三个 Lua 文件与本地实机拍摄使用的版本逐字节一致。本次首次公开发布没有加入临时拍摄脚本、全灭脚本或本机安装器。

本地游戏资源版本为 2.5；RED4ext 日志报告 Product version 2.50。测试的依赖组合在主 README 中列出。

## 离线验证

`tests/test_behavior.py` 使用 LuaJIT 2.1 / lupa 模拟引擎，覆盖：临时生成、跟随角色、重抽冷却、避免立即重复、剧情和载具限制、异步加载与删除、超时、异常回收、阵亡后拒绝召回、读档不自动重生、小队上限、取消、清理范围和退出清理。

`tests/test_package.py` 检查发布包文件白名单、游戏根目录布局和源文件校验，防止把本机运行状态、存档或依赖二进制误打包。

这些测试不会运行真实游戏，不证明战斗 AI、寻路或长期稳定性。

## 长时间会话崩溃：待定位

一次约 6 小时的本地会话结束时，RED4ext 捕获了引擎 `dynamicBuffer.cpp` 的整数溢出断言。当前没有稳定的最小复现步骤，不能据此确定是本模组、依赖、游戏引擎或它们之间的交互造成。

此记录是将首版标为实验预发布的原因之一。后续需要分别验证：不启用本模组、只使用单名队友、开启小队演示、战后清场，以及长时间留置临时小队时的内存和稳定性。

不会把这次崩溃描述为已经修复。模组默认关闭拍摄续航；建议结束演示时清理队伍。
