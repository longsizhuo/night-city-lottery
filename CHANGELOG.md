# Changelog

## 0.2.0 — 2026-11-02 · Initial public experimental prerelease

- Random temporary companions from ten ordinary combat configurations.
- Follow/combat role, out-of-combat recall, ten-second reroll cooldown and owned-actor cleanup.
- Four friendly reinforcements, 4v4 and 6v6 panel actions, up to 8v8 through the CET console API.
- Bounded, staged spawning; filming immortality is off by default.
- Chinese installation and gameplay guides, English quick start and known-issue notes.
- Mod-only ZIP, SHA256 checksum and mocked LuaJIT/package tests.

The Lua code is the locally play-tested v0.2.0 build. This publication does not claim to fix the unconfirmed long-session engine crash documented in `docs/TESTING.md`.
